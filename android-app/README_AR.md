# تطبيق Android المرافق لـ Kamal Moonshot

هذا مشروع Android Studio خفيف يفتح لوحة الرادار عبر اتصال HTTPS بخادم VPS. **المسح المستمر وTelegram يعملان على الخادم، لا داخل الهاتف**؛ لذلك يبقى الرصد شغالًا عندما تغلق التطبيق أو تطفئ هاتفك، ما دام VPS لديه إنترنت ويعمل. التطبيق لا يضيف تداولًا حقيقيًا، ويظل PAPER فقط.

## قبل تثبيت التطبيق

1. انشر مشروع Node على VPS واتبع `../VPS_SETUP_AR.md`.
2. اربط نطاق HTTPS فعليًا. لا تستخدم `http://127.0.0.1:8787` داخل التطبيق: `127.0.0.1` يشير للهاتف نفسه، وليس للخادم.
3. أضف Telegram إلى ملف البيئة السري للخادم واتبع `../TELEGRAM_SETUP_AR.md`.
4. اختبر اللوحة على نطاق HTTPS في المتصفح أولًا، ثم أدخل النطاق في التطبيق. رمز الإدارة يظل داخل جلسة صفحة الويب ولا يحفظه التطبيق الأصلي.

## بناء APK

- افتح مجلد `android-app` في Android Studio حديث مع Android SDK 35 وJDK 17.
- انتظر Gradle Sync، ثم اختر **Build > Build Bundle(s) / APK(s) > Build APK(s)**.
- للتثبيت على هاتفك، انقل ملف APK الناتج من `app/build/outputs/apk/debug/` وافتحه، مع السماح بتثبيت تطبيقات من هذا المصدر عند الحاجة.
- لإصدار عام، أنشئ مفتاح توقيع خاصًا بك واستخدم **Generate Signed Bundle / APK**. لا تشارك مفتاح التوقيع.

### البناء من GitHub Actions

ملف البناء الصحيح موجود في `.github/workflows/android.yml` بجذر المستودع. ادفع التغييرات إلى `main` أو شغّل سير العمل يدويًا من تبويب **Actions**؛ بعد نجاحه افتح تفاصيل التشغيل، ثم نزّل `KAMAL-MOONSHOT-HUNTER-debug-apk` من قسم **Artifacts**. المشروع موجود داخل مجلد `android-app`، لذلك يجب أن يبني Gradle من هذا المجلد، بينما مسار الملف المرفوع يبدأ من جذر المستودع.

المشروع يتضمن مصدر Java وملفات Gradle، لكنه لا يتضمن APK مبنيًا أو مفتاح توقيع. بيئة تجهيز الحزمة هنا لا تحتوي Android SDK أو Gradle، لذلك يجب بناء APK على Android Studio أو بيئة Android مجهزة.

## الخصوصية والأمان

- يقبل التطبيق عنوان HTTPS فقط ويربط التصفح بنفس النطاق والمنفذ؛ الروابط الخارجية تفتح في المتصفح.
- لا يوجد إذن لمحفظة أو ملفات أو كاميرا أو جهات اتصال، ولا يوجد سر API مضمّن داخل APK.
- خزّن `ADMIN_TOKEN` و`TELEGRAM_BOT_TOKEN` و`TELEGRAM_CHAT_ID` على VPS فقط، وليس في التطبيق ولا GitHub.
- التطبيق يعرض خدمة PAPER فقط، ولا يشغّل خلفية المسح على Android.
